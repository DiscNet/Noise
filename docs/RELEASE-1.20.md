# Noise! V1.20 — Corrigida a posição lateral da roda de efeitos

- A roda de **Ferramentas** ocupa um painel à **esquerda** do editor.
- A roda de **Efeitos** ocupa um painel à **direita** do editor (não apenas animação da esquerda para a direita).
- Os painéis agora são ancorados em lados opostos, com largura responsiva e espaço para visualização parcial da imagem.
- A geometria orbital, os ícones e as legendas foram espelhados para cada lado.
- Ferramentas usa ícone à esquerda e legenda à direita; Efeitos usa legenda à esquerda e ícone à direita.
- Arrastar da direita para esquerda abre Ferramentas, enquanto esquerda para direita abre Efeitos.
- Animações amortecidas, scroll e inércia mantidos, assim como o fade de escurecimento independente.
- Novos testes verificam os limites dos painéis em tela, os centros orbitais e o estado das ferramentas.
- Mantida a correção do controle Brancos e as funções existentes.

O APK `Noise.V1.20.apk` é compilado pelo GitHub Actions como prévia; o teste em emulador e a inspeção visual devem ser concluídos antes de uma release definitiva.
